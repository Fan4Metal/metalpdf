<p align="center"><a href="README.md">English</a> | <b>Русский</b></p>

MetalPDF — просмотрщик PDF, построенный вокруг одной идеи: документ должен быть на экране в момент появления окна, а при пролистывании никогда не должно быть пустых страниц. Он рисует страницы движком PDFium (движок PDF из Chromium), открывает документы во вкладках, которые можно вытащить в отдельные окна, ищет по тексту, выделяет текст, показывает миниатюры и оглавление, печатает, а также умеет изменить текст строки и сохранить результат. В программе нет диалога настроек и нет обращений в сеть, кроме необязательной проверки обновлений.

![MetalPDF с открытым учебником и панелью миниатюр](images/screenshot.png)

*Снимок окна версии 0.1.0.*

## Возможности

- **Мгновенно**: первая страница рисуется, пока окно ещё создаётся; учебник на 450 МБ и 1300 страниц открывается менее чем за 10 мс, а его первая страница оказывается на экране примерно через 160 мс после запуска программы (см. [Производительность](#производительность)).
- **Без пустых страниц**: страницы, к которым прокручивают, рисуются из ближайшего имеющегося рендера или маленького превью, пока не придёт точный; рендеры, которых уже никто не ждёт, прерываются на полпути.
- **Вкладки и окна**: несколько документов в одном окне, вытащенная вкладка становится окном; повторный запуск передаёт файлы работающей копии; последний сеанс открывается заново (см. [Вкладки и окна](#вкладки-и-окна)).
- **Непрерывная прокрутка или по одной странице**, по ширине, страница целиком или любой масштаб, повороты на четверть оборота, клавиатура просмотрщика (см. [Горячие клавиши](#горячие-клавиши)).
- **Боковая панель** с миниатюрами страниц и оглавлением документа; обе следуют за читаемой страницей.
- **Поиск** по всему документу с подсветкой найденного на страницах и списком находок на боковой панели; **выделение текста** мышью, копирование по Ctrl+C.
- **Ссылки** внутри документа и в веб, с историей для возврата.
- **Напечатанные номера страниц**: по книге, у которой страница 1 — семнадцатая в файле, переходят и печатают по номерам на её страницах (см. [Номера страниц](#номера-страниц)).
- **Правка** (экспериментально): текст строки меняется на месте, изображения перемещаются, масштабируются, заменяются и удаляются, страницы вставляются, заменяются и удаляются, документ сохраняется (см. [Правка текста, изображений и страниц](#правка-текста-изображений-и-страниц)).
- **Печать** с предпросмотром каждого листа: принтер, его бумага, ориентация и двусторонняя печать, страницы, копии и масштаб, собственные настройки принтера за кнопкой «Свойства» (см. [Печать](#печать)).
- **Миниатюры в Проводнике**: когда MetalPDF — программа по умолчанию для PDF, Проводник показывает вместо значков первые страницы файлов.
- **Формы** рисуются вместе с содержимым полей; **зашифрованные** документы запрашивают пароль.
- **Светлая, тёмная или системная тема**; тёмная — серая или почти чёрная.
- **Русский или английский интерфейс**: следует языку Windows и меняется в окне «О программе» (`F1`).
- **Портативность**: [портативный архив](#установка) хранит настройки рядом с программой.
- **Конфиденциальность**: никаких обращений в сеть, кроме необязательной проверки обновлений (см. [Проверка обновлений и конфиденциальность](#проверка-обновлений-и-конфиденциальность)).

## Установка

Установщик и портативный архив лежат на странице [Releases](https://github.com/Fan4Metal/metalpdf/releases). В обоих рядом с программой лежит `pdfium.dll` — движок рендеринга; без него программа запускается и сообщает, чего не хватает. Исполняемые файлы не подписаны, поэтому Windows SmartScreen при первом запуске может предупредить о неизвестном издателе («Подробнее» → «Выполнить в любом случае»).

- **Установщик** `MetalPDF_<версия>_Setup.exe` не требует прав администратора: программа помещается в `%LOCALAPPDATA%\Programs\MetalPDF`, хранит настройки в `%APPDATA%\MetalPDF\config\settings.json` и предлагается для файлов PDF в меню «Открыть с помощью» и в Параметрах → Приложения по умолчанию (программой по умолчанию она сама себя не делает).
- **Портативный архив** `MetalPDF_<версия>_portable.zip` содержит программу в папке `MetalPDF` и работает без установки; настройки хранятся рядом с ней, так что программу можно носить на съёмном диске.

<details>
<summary>Миниатюры в Проводнике и где портативная программа хранит настройки</summary>

- **Миниатюры**: когда MetalPDF выбрана программой по умолчанию для файлов PDF, Проводник показывает вместо их значков миниатюры первых страниц: их рисует входящий в установку `metalpdf_thumbs.dll` тем же движком PDFium. Файл, для которого миниатюра уже строилась, сохраняет картинку из кэша Проводника, пока кэш миниатюр не очищен («Очистка диска» → «Эскизы») или файл не изменился.
- **Настройки портативной версии**: в архиве лежит пустой файл `metalpdf.json`. Пока этот файл находится рядом с `metalpdf.exe` и папка доступна для записи, настройки хранятся в нём. Без файла программа хранит их в `%APPDATA%\MetalPDF`, как и установленная. Окно «О программе» показывает, где хранятся настройки. Файл настроек, который не удалось прочитать, сохраняется рядом под расширением `.json.bad`, а программа берёт настройки по умолчанию.

</details>

## Использование

PDF открывается через `Ctrl+O`, перетаскиванием на окно, из списка недавних файлов на стартовом экране, из Проводника (двойным щелчком, если MetalPDF выбран для файлов PDF, или через «Открыть с помощью») либо из командной строки: `metalpdf.exe файл.pdf`. Каждый файл открывается во вкладке; уже открытый файл просто выводится вперёд. Место, где оставлен каждый документ (страница, масштаб, повороты), запоминается, как и последний сеанс: запущенный без файлов, MetalPDF открывает вкладки, с которыми был закрыт.

<details>
<summary>Панель инструментов и строка вкладок</summary>

На панели инструментов под вкладками (на стартовом экране её нет) находятся:

- поле страницы: введённый туда номер страницы или метка вроде `iv` ведёт на эту страницу; `Ctrl+G` ставит в него курсор;
- масштаб с меню и три пресета масштаба: истинный размер, по ширине, страница целиком (клавиши `1`, `2`, `3`); действующий подсвечен, а выбранный пресет становится масштабом, с которым открываются новые документы;
- две кнопки поворота;
- режим просмотра: непрерывно или по одной странице, где полоса прокрутки по-прежнему охватывает весь документ, а её перетаскивание листает страницы;
- текстовый инструмент и рука, карандаш режима правки и принтер, открывающий диалог печати;
- справа — заметка об отказе в правке или о сохранении файла и ход печати с крестиком для отмены.

В строке вкладок — переключатель боковой панели, «Открыть», вкладки, а справа переключатель темы (его контекстное меню выбирает между серой и почти чёрной тёмной темой), кнопка обновления, когда вышла новая версия, и «О программе».

</details>

### Вкладки и окна

Вкладки переключаются по `Ctrl+Tab` и `Ctrl+Shift+Tab`, закрываются по `Ctrl+W` или крестиком, открываются заново по `Ctrl+Shift+T`, а перетаскиванием меняют порядок. Вкладка, вытащенная из строки вкладок, становится отдельным окном; перетащенная на другое окно MetalPDF — переезжает туда. Контекстное меню вкладки предлагает то же самое и «Закрыть остальные».

<details>
<summary>Одна копия на сеанс и командная строка</summary>

На сеанс пользователя работает одна копия MetalPDF: повторный запуск (двойной щелчок в Проводнике, командная строка) передаёт файлы работающей копии, которая открывает их в последнем использованном окне и выходит на передний план. Параметры командной строки:

| Параметр | Что делает |
|---|---|
| `--new-instance файл.pdf` | Запускает отдельную копию вместо передачи файлов |
| `--register`, `--unregister` | Предлагают MetalPDF для файлов `.pdf` в «Открыть с помощью» Windows и отзывают это предложение (их выполняет установщик) |
| `--bench файл.pdf` | Печатает время работы движка на файле |
| `--screenshot файл.png файл.pdf` | Записывает снимок окна через несколько кадров и выходит |
| `--export-icon файл.ico` | Записывает значок приложения |
| `--version`, `--help` | Версия, список параметров |

</details>

### Боковая панель

`F4` (или кнопка слева от «Открыть») показывает панель со списками: **«Страницы»**, **«Оглавление»**, а при открытой строке поиска и **«Поиск»**. Она стоит слева или справа в окне, как выбрано в контекстном меню этой кнопки или вкладок списков; её ширина запоминается.

<details>
<summary>Три списка</summary>

- **«Страницы»** — все страницы в виде миниатюр; текущая обведена и удерживается на виду, щелчок ведёт на страницу. Контекстное меню миниатюр вставляет, заменяет и удаляет страницы (см. [Правка](#правка-текста-изображений-и-страниц)).
- **«Оглавление»** — закладки документа деревом: уровни различаются размером, насыщенностью и отступом с направляющими линиями, у каждой закладки номер страницы; главы свёрнуты, кроме той, где находится читатель, а его закладка подсвечена; щелчок переходит к закладке, щелчок по треугольнику сворачивает или разворачивает её.
- **«Поиск»** — находки поиска по страницам, каждая в её строке, совпадение подсвечено как на странице, текущее отмечено; щелчок ведёт к находке.

</details>

### Поиск

`Ctrl+F` открывает строку поиска. Поиск начинается с читаемой страницы и обходит документ по кругу, страница за страницей; найденное подсвечивается на страницах, текущее совпадение — ярче, а строка показывает, которое это совпадение из скольких. `Enter` и `F3` ведут к следующему совпадению, `Shift+F3` — к предыдущему; `Esc` закрывает строку.

<details>
<summary>Параметры и список находок</summary>

- `Aa` и <u>ab</u> на строке поиска включают учёт регистра и поиск только целых слов. Регистр сравнивается по правилам Unicode (кириллица так же, как латиница), пробел в запросе совпадает с переводом строки, а границы слов различаются в любой письменности.
- Пока поиск продолжается, у счётчика стоит знак плюс.
- Начало поиска открывает боковую панель на вкладке **«Поиск»** со списком находок по страницам; закрытие поиска возвращает панель в прежнее состояние.

</details>

### Выделение текста, ссылки и контекстное меню

Текст выделяется протягиванием мыши, в том числе через несколько страниц, и копируется по `Ctrl+C`; `Ctrl+A` выделяет текст текущей страницы, `Esc` снимает выделение, двойной щелчок выделяет слово. Над текстом указатель принимает вид I-образного курсора, над ссылкой — руки; ссылка внутри документа ведёт к цели, веб-ссылка открывается в браузере. `Alt+←` (или кнопка «назад» на мыши) возвращает из перехода по ссылке, закладке, миниатюре, полю страницы или совпадению; `Alt+→` повторяет переход.

<details>
<summary>Контекстное меню и два инструмента</summary>

- **Правая кнопка над страницами** открывает меню: копировать выделение, выделить страницу, скопировать картинку под указателем (в буфер обмена, в её собственном разрешении, как показана: с масками и прозрачностью), открыть ссылку или скопировать её адрес, инструменты, а в режиме правки — отрезок текста или картинку под указателем.
- **Инструменты** — на панели инструментов: с текстовым (`V`) протягивание выделяет текст; с рукой (`H`) — прокручивает страницы, которые, если их отпустить, катятся дальше по инерции, а в режиме одной страницы перетаскивание, заведённое далеко за край страницы, перелистывает её в любую сторону. Двойной щелчок выделяет слово под указателем при любом из них.

</details>

### Номера страниц

Когда напечатанные на страницах номера отличаются от номеров в файле (скажем, страница 1 книги — семнадцатая в файле), правая кнопка на поле номера страницы предлагает прочитать напечатанные номера со страниц, указать номер показанной страницы или вернуться к нумерации файла.

<details>
<summary>Как используются напечатанные номера</summary>

Чтобы прочитать номера, берутся две дюжины страниц и принимается сдвиг, с которым они согласны. Поле номера, миниатюры, оглавление и список находок после этого показывают напечатанные номера (страницы до первой — римскими цифрами, как вводная часть книги), введённый в поле номер понимается как напечатанный, диалог печати читает по ним список страниц, а настройка хранится вместе с позицией в документе. Документ с собственными метками страниц (например, римскими номерами предисловия) показывает их как есть.

</details>

### Правка текста, изображений и страниц

Режим правки (`E` или карандаш на панели инструментов) обводит строки текста и изображения на страницах. Щелчок по строке открывает над ней поле со всей строкой; `Enter` применяет изменение, `Esc` оставляет строку как было, `Ctrl+Z` отменяет последнее изменение. Щелчок по изображению выделяет его, чтобы переместить, изменить размер, заменить или удалить. Страницы вставляются, заменяются и удаляются из контекстного меню миниатюр. Изменения живут в копии документа, пока `Ctrl+S` не сохранит её. Эта часть программы экспериментальна; для ценного документа лучше работать с копией.

<details>
<summary>Строки текста</summary>

PDF нередко записывает строку множеством текстовых объектов, разрезанных везде, где у пары букв есть кернинг; объекты на одной базовой линии, идущие друг за другом, правятся как одна строка. В один объект сливаются только те объекты, которых коснулось изменение; остальные объекты строки остаются прежними, а часть строки после изменения сдвигается вдоль неё на разницу в ширине, так что более длинному тексту хватает места и ничего не накладывается. Текст не переносится: удлинённая строка заходит дальше вправо.

</details>

<details>
<summary>Шрифты</summary>

Отрезок сохраняет свой шрифт, а с ним и вид, всякий раз, когда этот шрифт способен показать новый текст; шрифт, встроенный как подмножество глифов, способен на это для символов, которые в нём есть (скажем, цифр даты). Лишь когда глифа нет, отрезок набирается подменным шрифтом на том же месте, того же размера и цвета: тем же шрифтом, если он установлен на компьютере (он ищется по имени из документа среди шрифтов Windows и пользователя), иначе Arial, Times New Roman или Courier New по виду исходного, в его насыщенности и наклоне, так что жирный отрезок остаётся жирным; и подогнанным по ширине исходного отрезка, так что правка той же длины занимает ту же рамку. Отрезок под указателем показывает свой шрифт и размер и установлен ли этот шрифт: если нет, его установка сделает замену точной.

</details>

<details>
<summary>Изображения и страницы</summary>

- **Изображения**: щелчок выделяет изображение; его перемещают перетаскиванием, а размер меняют за угловые маркеры (пропорции сохраняются); кнопка **«Заменить…»** ставит на его место файл JPEG или PNG, вписанный в прежнюю рамку с собственными пропорциями, а **«Удалить»** (или клавиша `Del`) убирает его.
- **Страницы** — из контекстного меню миниатюры в боковой панели: вставить перед ней или после неё пустую страницу (размером с соседнюю) либо все страницы другого файла PDF, заменить страницу страницами другого PDF, удалить страницу (последняя остаётся). Режим правки для этого не нужен.

</details>

<details>
<summary>Сохранение и что не правится</summary>

- **Сохранение**: `Ctrl+S` открывает диалог «Сохранить как» с предложенным именем `имя_edited.pdf`, так что оригинал заменяется только по выбору; затем вкладка показывает сохранённый файл. Закрытие вкладки или выход с несохранёнными изменениями сначала спрашивает.
- **Подписанные и зашифрованные документы** не редактируются.
- **Тегированные (доступные) документы**: изменённый фрагмент текста сохраняет отметки, на которые ссылаются теги, в том числе при замене шрифта; у удалённого изображения тег остаётся пустым, а структура тегов при вставке и удалении страниц не обновляется.
- **Form XObject**: текст и изображения внутри них, куда некоторые генераторы кладут всю страницу, недоступны.
- **Страница, которую PDFium не может записать как есть**, не редактируется: текст шрифтом Type 3 (так Chrome и Edge печатают вариативные шрифты, например Cascadia — код на веб-странице), градиенты в виде shading и встроенные (inline) изображения при сохранении были бы потеряны, а заливки узором, мягкие маски и два разных шрифта с одним именем вышли бы искажёнными, поэтому такая правка отклоняется: прежде чем принять правку, страница сравнивается со своим записанным содержимым. Цвета в CMYK, оттенках серого и плашечных красках сохраняются как показанный цвет.
- Отказ в правке объясняется в заметке справа на панели инструментов.

</details>

### Печать

`Ctrl+P` или пункт «Печать» в контекстном меню страниц открывает диалог печати. Слева он показывает каждый лист таким, каким тот напечатается, а стрелки под ним листают листы; справа — принтер, его бумага, ориентация и двусторонняя печать, страницы, копии и масштаб. Печать идёт в фоне, по странице, а её ход и крестик для отмены видны справа на панели инструментов.

<details>
<summary>Диалог печати подробно</summary>

- **Предпросмотр** показывает бумагу, доступную принтеру часть и размещённую на ней страницу.
- **Принтер** — последний использованный, иначе принтер Windows по умолчанию; бумага, ориентация и двусторонняя печать предлагаются, если принтер их поддерживает, а **«Свойства…»** открывает собственный диалог принтера для остального (качество, цвет, лотки).
- **Страницы** — все, текущая или список вида `1-5, 8, 11-`, который читается так же, как поле страницы, так что книга, пронумерованная по напечатанным номерам, и печатается по ним. Копии по запросу разбираются по экземплярам.
- **Масштаб**: страница больше печатной области по умолчанию уменьшается до неё; вместо этого её можно вписать в лист, напечатать в истинном размере или в своём масштабе (10–800 %, по центру листа, с обрезкой по его краям), а документ, который просит не масштабировать его, открывается с истинным размером. Альбомная страница на книжном листе поворачивается, и наоборот, если это не отключено.
- **Векторы или изображения**: страницы уходят на принтер векторами, которые рисует PDFium, вместе с заполненными полями форм. **«Печатать как изображение»** вместо этого отправляет каждую страницу картинкой 300 dpi — для принтера, который неверно печатает векторный вывод; так медленнее и объёмнее.
- Документ с несохранёнными правками печатается таким, каким он показан; выход во время печати сначала спрашивает. Текст, напечатанный на PDF-принтер, получается контурами, а не выделяемым текстом.

</details>

## Производительность

Первая страница оказывается на экране примерно через 160 мс после запуска программы: поток движка открывает первый файл и рисует его первую страницу, пока создаётся окно, в размере, предсказанном по сохранённому окну, так что первый кадр застаёт страницу готовой.

<details>
<summary>Измерения</summary>

Измерено на i7-13700KF с RTX 4070 Ti SUPER и дисплеем 4K при масштабе 150 % командой `metalpdf.exe --bench файл.pdf` (только движок) и с `METALPDF_TRACE=1` (окно):

| Шаг | Время |
|---|---|
| Загрузка и инициализация `pdfium.dll` | 2 мс |
| Открытие файла на 2 страницы; учебника на 454 МБ и 1347 страниц | 0,2 мс; 9 мс |
| Чтение размеров всех 1347 страниц | 16 мс |
| Рендер текстовой страницы шириной 1626 px; страницы с большими изображениями | 3–5 мс; 17 мс |
| Превью страницы шириной 200 px | 0,1–3 мс |
| Первая страница на экране (загружена в GPU) после запуска программы | 160 мс |
| Показ окна | 210–250 мс |

Первый запуск на машине медленнее: DLL читается с диска.

</details>

## Проверка обновлений и конфиденциальность

MetalPDF не обращается в сеть, за одним исключением: проверка обновлений, **выключенная по умолчанию**. Если её включить в окне «О программе» (`F1`), программа раз в сутки при запуске и по кнопке «Проверить сейчас» спрашивает у `api.github.com` последний выпуск этого репозитория; запрос несёт в себе имя и версию программы в качестве user agent и ничего больше, и ничего не скачивается. Новая версия показывается кнопкой в строке вкладок, которая открывает страницу выпуска в браузере. Открытые документы, недавние файлы и настройки никогда не покидают компьютер.

## Сборка

Требуются Windows 10 или новее, Rust (stable, MSVC), Visual Studio 2022 Build Tools с рабочей нагрузкой C++, Python 3 и [uv](https://docs.astral.sh/uv/); для установщика — Inno Setup 6.

```
uv run build.py          # target\release\metalpdf.exe и pdfium.dll рядом с ним
cargo test
```

<details>
<summary>Как устроена сборка</summary>

Скрипт закрывает `metalpdf.exe`, запущенный из `target\`, скачивает закреплённую `pdfium.dll` в `vendor\pdfium`, если её нет (`tools\get_pdfium.py`, с проверкой SHA-256), и выполняет `cargo build --release`; сборка копирует DLL рядом с `target\release\metalpdf.exe`, где лежит и собранный вместе с программой `metalpdf_thumbs.dll` — поставщик миниатюр для Проводника. `cargo test` выполняет модульные тесты; `cargo test pdfium -- --ignored --test-threads=1` задействует и DLL (PDF, написанный тестом, открывается, рисуется, читается, правится и сохраняется). `metalpdf.exe --bench файл.pdf` печатает тайминги движка для файла. Исполняемый файл компонует библиотеку времени выполнения C статически и загружает PDFium во время работы, так что ему не нужно ничего, кроме Windows и `pdfium.dll`.

</details>

<details>
<summary>Настройка окружения и раскладка исходников</summary>

Инструменты устанавливаются через winget:

```
winget install Rustlang.Rustup Microsoft.VisualStudio.2022.BuildTools astral-sh.uv Python.Python.3.13 JRSoftware.InnoSetup
rustup default stable-msvc
```

Для Build Tools в Visual Studio Installer выбирается рабочая нагрузка «Разработка классических приложений на C++».

| Путь | Содержимое |
|---|---|
| `src/pdfium/` | C API PDFium, объявленный вручную (`sys.rs`), и безопасный слой над ним (`mod.rs`): документы, страницы, рендер (обычный и прогрессивный), текст, поиск, ссылки, закладки, правка, сохранение |
| `src/engine.rs` | Единственный поток, из которого вызывается PDFium, с планировщиком рендеров |
| `src/layout.rs`, `src/view.rs` | Геометрия страниц и состояние вида |
| `src/app.rs` | Окна и вкладки |
| `src/ui/` | Область страниц, строка вкладок, панель инструментов, боковая панель, диалог печати, «О программе», окно лицензий, нарисованные иконки |
| `src/settings.rs`, `src/single_instance.rs` | Настройки в JSON; передача файлов между запусками |
| `thumbs/` | `metalpdf_thumbs.dll` — поставщик миниатюр для Проводника |
| `tools/` | `get_pdfium.py`, `make_release.py`, `notices.py`, `setup.iss` |

</details>

## Установщик и выпуск

Скрипт выпуска собирает исполняемый файл, установщик и портативный архив. Ему нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```
python tools\make_release.py                        # PDFium, тесты, сборка, установщик, архив
python tools\make_release.py --no-tests --install   # то же, затем тихая установка поверх установленной копии
```

<details>
<summary>Порядок выпуска</summary>

Скрипт записывает `dist\MetalPDF_<версия>_Setup.exe` и `_portable.zip` и берёт версию из `Cargo.toml`. Сценарий установщика — `tools\setup.iss`; `metalpdf.exe --export-icon <файл.ico>` записывает значок установщика.

Выпуски на GitHub собирает workflow **Release** (`.github/workflows/release.yml`). Между выпусками версия в `Cargo.toml` несёт суффикс `-dev`. Выпуск снимает суффикс (после `python tools/notices.py`, если `Cargo.lock` изменился: тест проверяет уведомления), фиксируется коммитом `Version X.Y.Z`, а push совпадающего тега публикует его с установщиком и портативным архивом; затем ставится следующая версия с `-dev`:

```
git tag v0.1.0
git push origin v0.1.0
```

Workflow останавливается, если тег не совпадает с версией в `Cargo.toml`.

</details>
